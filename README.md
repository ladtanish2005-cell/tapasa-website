# TAPASA — Luxury Living Spaces

A luxury furniture and architectural atelier web application built with Next.js, React, and Tailwind CSS.

---

## 🚀 Quick Start Guide (For Anyone Opening This Project)

### Step 1: Extract the Zip File
> ⚠️ **IMPORTANT**: Do NOT run directly inside the `.zip` archive!
> Right-click the `.zip` file and select **"Extract All..."**, then open the extracted folder.

### Step 2: Running the Project

#### Option A: One-Click (Windows)
If you have **Node.js** installed:
1. Double-click the **`start.bat`** file.
2. It will automatically install any required packages, start the server, and launch the site at **`http://localhost:3000`** in your default web browser!

#### Option B: Terminal / Command Line
1. Open PowerShell or Command Prompt in this folder.
2. Run:
   ```bash
   npm install --legacy-peer-deps
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## ✨ Features Tested & Working
- **Full Navigation**: Interactive links to Collection, About, Showrooms, Contact, and Privacy/Terms.
- **Product Catalog**: Filter by Seating, Tables, Storage.
- **Product Details (`/products/[id]`)**: Full specifications, artisanal timber finishes, quantity selector, custom inquiries, and related pieces.
- **Interactive Search**: Search products in real-time from the navbar.
- **Private Concierge Modal**: Quick access to design consultation details.
- **Room Showcase**: Interactive Living Room and Bedroom views with product tags.
- **Showrooms & Map Links**: Flagship Mumbai & Bengaluru design studios with direct Google Maps navigation.
- **Inquiry Form**: Validated contact form with confirmation states.
- **Responsive Design**: Mobile-friendly navigation drawer and adaptive imagery.
